## 🚨 CRITICAL ISSUES (Must Fix)

### 1. BUILD FAILURE — Static Prerendering Error
**File:** All pages using Convex hooks
**Error:** `Could not find Convex client! useQuery must be used in React component tree under ConvexProvider`
**Cause:** Next.js 16 tries to statically prerender pages. Convex hooks fail outside ConvexProvider context during SSG.
**Fix:** Add `export const dynamic = "force-dynamic"` to all protected pages, OR wrap in a layout with Suspense boundary.

### 2. NO SESSION SECURITY
**File:** `src/lib/auth.tsx`
**Issue:** Auth is stored as plain user ID in `localStorage`. No token, no expiry, no server-side validation.
- Anyone who knows a Convex document ID can impersonate any user
- No session expiry or timeout
- No CSRF protection
**Impact:** HIGH — any client could access admin data by changing localStorage

### 3. PASSWORD HASHING IS WEAK
**File:** `convex/projects.ts`
**Issue:** SHA-256 without salt. Identical passwords produce identical hashes.
**Impact:** If Convex DB is exposed, rainbow table attacks trivial
